Extract and Search PDF Text

Read embedded PDF text layers, search keywords across every page, or run offline macOS Vision OCR on scanned image PDFs.

How to Extract PDF Text in Mac PDF Editor

  1. Open your PDF in Mac PDF Editor or connect via the local HTTP API (127.0.0.1:4890).
  2. For scanned PDFs without an embedded text layer, click OCR to run Apple Vision recognition.
  3. Query extract_text or search_text via API/MCP or edit any highlighted line directly in the UI.
