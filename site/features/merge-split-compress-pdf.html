Merge, Split, Rotate & Compress PDFs with Rust

Mac PDF Editor pairs a fast thumbnail sidebar with a native Rust PDF engine (lopdf) and zero-copy binary IPC so even 25-page, 16+ MB documents save and compress in milliseconds.

Page Management Tools

  • Reorder Pages: Move any page up or down in the sidebar with live thumbnail previews.
  • Rotate 90°: Rotate pages while keeping all added text, signatures, and highlights aligned 1:1 on export.
  • Duplicate & Delete: Clone template pages or remove unwanted sheets with full Undo/Redo (⌘Z / ⇧⌘Z).
  • Extract Single Page (Split): Save any individual page, along with its edits, as a standalone PDF file.
  • Merge PDFs: Append one or more external PDF files into the active document.

Rust lopdf Compression & Metadata

Clicking Compress runs prune_objects() and compress() in Rust directly on the current document state, even before you save to disk. You can also inspect PDF version, file size, title, author, and creator in the Inspector.
