Inspect and Edit PDF Metadata

Read PDF version, file size, page count, title, author, and creator using Rust lopdf, and update Info dictionary fields cleanly.

How to PDF Metadata in Mac PDF Editor

  1. Open any PDF to automatically inspect its version, size, title, author, and creator in the Inspector.
  2. Use the Rust lopdf backend command set_pdf_metadata to update Title, Author, Subject, or Creator.
  3. Save the updated document and verify metadata in any PDF viewer.
