Automate PDFs with Built-In MCP Server & HTTP API

Mac PDF Editor is one of the first desktop PDF editors with a native Local HTTP Control API (http://127.0.0.1:4890) and a zero-dependency Model Context Protocol (MCP) server (mcp/server.mjs).

Connect to Claude Desktop, Cursor, or Antigravity

{
  "mcpServers": {
    "mac-pdf-editor": {
      "command": "node",
      "args": ["/path/to/mac-pdf-editor/mcp/server.mjs"]
    }
  }
}

Available MCP Tools & API Actions

  • pdf_editor_health / GET /health — verify app status
  • pdf_editor_get_state / GET /state — inspect open file, pages, zoom, metadata
  • pdf_editor_open — open any local PDF in the live UI
  • pdf_editor_extract_text & pdf_editor_search_text — read & search PDF content
  • pdf_editor_add_annotation — programmatically place text, highlights, rectangles, signatures, or stamps
  • pdf_editor_page_rotate, page_duplicate, page_delete — manipulate pages
  • pdf_editor_save, pdf_editor_compress, pdf_editor_export_png — save, compress via Rust lopdf, and export PNG
