Merge PDF Files Offline

Combine multiple PDF documents into one file locally without uploading sensitive files to online converters. Powered by pdf-lib and Rust.

How to Merge PDF in Mac PDF Editor

  1. Open the first PDF document in Mac PDF Editor (⌘O).
  2. Click the Merge button in the top toolbar and select one or more additional PDF files.
  3. Review the combined page thumbnails in the sidebar and press ⌘S to save the merged PDF.
