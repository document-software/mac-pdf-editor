Edit Existing PDF Text Seamlessly

Unlike basic viewers that only let you drop a plain text box on top of a document, Mac PDF Editor detects existing text runs via pdfjs-dist and makes every editable line clickable.

1. Instant Highlighting of Editable Blocks

Activate the Text (T) tool and every selectable text block on the page is highlighted with a subtle dashed blue outline. You immediately know which parts of the PDF contain a native text layer and which parts are scanned images (which you can convert with macOS Vision OCR).

2. Exact Bounding-Box Sizing

Clicking any highlighted block opens an inline <textarea> pre-filled with the original string and matched to the exact pixel width and height of the PDF text run. As you type longer sentences, the editor expands dynamically instead of wrapping unexpectedly.

3. Automatic Background Color Sampling

Many PDFs use cream paper, light gray cards, or colored headers instead of pure #ffffff. Before replacing text, sampleBackgroundColor() reads 16 perimeter pixels directly from the rendered HiDPI canvas, computes the median RGB color, and uses it for both the on-screen preview and the exported PDF rectangle. On dark backgrounds, the replacement text color automatically switches to white.

4. Full Unicode & Cyrillic Support

When saving with pdf-lib, standard ASCII strings are embedded as native vector text, while Cyrillic, accented, and Unicode characters are rendered at 3x Retina scale to crisp PNG overlays so every language exports reliably without font-encoding errors.
