Everything Your PDF Workflow Needs

Built with Tauri v2, Rust (lopdf), PDF.js, pdf-lib, and Apple’s on-device Vision framework.

01 Edit Existing PDF Text Highlights every editable text block on the page, matches input dimensions to the original run, and samples background pixels automatically. Explore text editing
02 Offline macOS Vision OCR Recognizes scanned pages locally using Apple’s native Vision framework (English and Cyrillic) without cloud uploads. Read OCR details
03 Merge, Split, and Compress Reorder, rotate 90°, duplicate, delete, or extract single pages, and compress documents with the Rust lopdf engine. View page tools
04 Annotate, Whiteout, and Sign Highlight text, draw freehand signatures, insert PNG or JPG stamps, redact sensitive lines, and export pages to PNG. See markup tools
05 MCP Server and HTTP API Let Claude Desktop, Cursor, or Antigravity inspect, annotate, and export open documents over stdio MCP or 127.0.0.1:4890. Read API docs
06 Zero Subscriptions MIT-licensed desktop binary (~6 MB) built as a fast alternative to Adobe Acrobat Pro and PDF Expert. Compare editors
