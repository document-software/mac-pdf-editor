Rotate PDF Pages Permanently

Rotate sideways PDF pages by 90, 180, or 270 degrees on macOS while keeping added text, highlights, and signatures aligned 1:1.

How to Rotate PDF in Mac PDF Editor

  1. Select the sideways page in the thumbnail sidebar or page navigator.
  2. Click the 90° Rotate button in the toolbar until the orientation is upright.
  3. Save the file (⌘S); Mac PDF Editor normalizes the rotated page so annotations stay aligned.
